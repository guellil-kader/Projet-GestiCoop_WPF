GESTICOOP — Application WPF de gestion des offres de stage

Technologies :
- C# et WPF
- XAML pour l'interface
- .NET 8 pour Windows

Pour lancer le projet :
1. Décompressez GestiCoop.zip.
2. Ouvrez GestiCoop.csproj avec Visual Studio 2022.
3. Assurez-vous d'avoir installé la charge de travail « Développement .NET Desktop ».
4. Choisissez la configuration Debug et appuyez sur F5.

Fonctions présentes :
- Formulaire de publication d'une offre de stage
- Validation des champs et des dates
- Liste d'offres de démonstration
- Recherche et filtre par statut
- Modification et suppression d'offres

Important :
Les données sont conservées en mémoire pendant l'exécution. Elles ne sont pas encore sauvegardées dans une base de données. SQLite pourra être ajouté dans une étape suivante.
